# Taller CI/CD - Proyecto GPS

Repositorio del taller de Construcción y Evolución de Software para organizar
el trabajo del proyecto GPS y sus ramas de Git.

## Ramas

- `master`: versión estable del proyecto.
- `desarrollo`: integración del trabajo en curso.
- `pruebas`: validación y pruebas de los cambios.

## Flujo de trabajo

1. Crear ramas de trabajo desde `desarrollo`.
2. Integrar y validar los cambios en `desarrollo`.
3. Llevar a `pruebas` los cambios que deban verificarse.
4. Integrar en `master` únicamente los cambios aprobados.
